# 动画美术验收 v01

这是 2026-11-06 制作的独立美术样片，等待用户验收。游戏仍为 v0.14.0。本目录没有接入游戏资源构建。

双击 [index.html](index.html) 打开验收页。支持切换动作、暂停、重新播放、单帧前进、拖动时间轴、慢放、背景与地面格线切换。左侧放大查看细节，右侧显示参考游戏尺寸。地格为 2:1 菱形，动作稿尚需逐方向做正式接地标定。

也可直接播放 [动画总览.mp4](动画总览.mp4) 或 [动画总览.webp](动画总览.webp)。

## 美术来源与保留内容

使用内置 `image_gen`，以项目既有 `art/source/isometric/packed/hd-squad.png`、`hd-engineer.png`、`hd-tank.png`、`hd-factory.png` 为形象与材质参考。完整提示词在 [prompts.json](prompts.json)，修订提示词在 [refinement-prompts.json](refinement-prompts.json)。

沿用橄榄军服与装甲、冷灰蓝屋面、灰色混凝土、黄色工程标识和青蓝阵营色。`sheets` 保留透明 PNG 原稿。建筑损毁的第二稿降低烟尘并修复画格边缘截断；工兵第二稿移除白色背景。播放器使用 `ruin-v2.png` 与 `repair-v2.png`，首稿仅供比对。

本轮是蓝方代表视角的动作与风格验收，并非所有单位、所有建筑、八方向、双方阵营的完整生产图集。图像生成的姿态间仍有细部变化，需要在正式接入前统一武器、装备轮廓和关节，并沿用游戏中的投影校准步骤；不能直接把分帧原稿当作最终碰撞或射击方向依据。

建议确认本轮风格后，按同一套源模型与骨架制作八方向行进及射击，建筑沿用既有占地与门位，分离枪口火光、弹壳、施工火花和烟尘，使这些效果不改变单位轮廓与选中范围。后续同系列还应覆盖工厂开门出厂、矿车装卸、建筑待机设备、车辆受损与报废。

## 复现预览

预览页可直接离线打开，无需安装任何工具。若需重新导出，安装 Playwright 与 Edge、Python/Pillow、FFmpeg，然后在项目根目录执行：

```text
node scripts/export-animation-review.cjs --export
```

可用 `PLAYWRIGHT_MODULE` 指定已安装的 Playwright 包位置。导出器先检查七组素材、选择、暂停、单帧、背景与格线，再生成总览和七个独立动图。Python 仅把已渲染帧封装成 WebP，不绘制或修改原稿。

游戏可执行文件 SHA256 应保持为 `0B6DBB1D6F5E4FDB516E7349EE137FAFD31C1B372E542BCB79D1536E5D7ADBDC`。
