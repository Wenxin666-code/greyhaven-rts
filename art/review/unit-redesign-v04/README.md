主战坦克保持现有低炮塔、宽履带和分层装甲，不在本批重绘。车辆机械结构、人体衣褶、护具和材质层次必须达到至少与主战坦克实际模型相当的完成度。蓝色区域是未来独立涂装面的设计指引，成图本身尚未拆分灰度涂装层；后续仍需支持任意势力颜色。

## 后续模型落实要求

先确保主要轮廓、结构留空、长宽高和装备位置一致，再处理次级细节。不可只提高图集分辨率或给旧方块车体增加小附件。保持当前游戏显示比例，不为辨识度直接放大碰撞或恢复大车身。背面参考仅辅助造型，生成图不同视角仍可能有轮组数目、附件位置等差异，需要在统一模型中解决。

本图不是可直接使用的多方向素材，也不是实际游戏截图。剪影用于比较设计语言，不是精确游戏缩放验收；后续应从同一模型渲染全部朝向，在原生游戏默认镜头下检查，尤其检查炮架/起重架的转向与遮挡。工程作业臂、矿车铰接和火炮支撑结构当前仅为美术设计，未新增对应玩法或动画。
