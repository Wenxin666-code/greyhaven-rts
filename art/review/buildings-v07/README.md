## 延续的美术要求

- 明确棱角、层次清楚的工业结构，保持同一等距视角、材质、光照及投影方向；细节精致，同时让主体轮廓在缩小时依然可读。
- 每类建筑通过观察塔、坡顶、门洞、龙门架、机组、阵面、反射天线、炮座或输送线辨识用途。
- 军用建筑保留足够大的连续势力色区域，中性色材质不随势力改变；中立房屋初始灰白，占领后可染色。
- 正式制作需沿用现有地格、单位比例、地基和出口；台阶、坡道等落地构件收在占格内。单张展示的放大倍率不等同于游戏尺寸。

这些图片是视觉蓝本，蓝色与灰白色面板只表达未来涂装范围；真实遮罩、透明图集、地基校准、多视角和动画均在验收后制作。原有素材和早期归档完整保留。
