# 围墙与采油井

围墙采用预制混凝土、钢制压顶和可染色护板。每段占一格，四个方向的连接组合共 16 种。连接点在地格边界，端点保留封闭的柱面。采油井占 2 × 2 格，由抽油机、井口、管线、缓冲罐和检修柜组成。

- `models.js` 是可编辑建模源文件，沿用现有建筑的几何工具与材质。 `models/` 保存按部件分组的 Three.js 模型。
- `sprites/` 保存透明底图与独立染色层。每帧 320 × 320，地面锚点为 (160, 220)。围墙图集按连接值从 0 到 F 排列，油井图集按 0°、90°、180°、270°排列。
- `review/战场比例.png` 使用现有地表、精炼厂、哨戒炮和坦克做比例对照。 `review/建模细节.png` 展示结构、方向与势力染色。
- `review/采油井前后对照.png` 同角度对照采油井细化前后的支架、传动、井口和储油罐。
- `review/采油井染色前后对照.png` 同角度对照扩大涂装前后的采油井。储油罐、机头、摆梁上盖、配重和检修柜外壳使用独立染色层。

项目已有 Playwright 时可运行 `node scripts/export-fieldworks.cjs` 重新导出。亦可通过 `PLAYWRIGHT_MODULE` 指定本机安装位置。静态验收图和可编辑模型存放在美术源文件目录。

已有图集时可加 `--oilwell`，单独导出采油井并用上次的采油井图集制作对照图。
同时加 `--paint-review` 可生成单独的涂装对照图。

## 采油井待机

曲柄每 6 秒转一周，两个等长连杆带动摆梁。悬绳与抽油杆沿井口上下移动，底座和储油罐固定。 `models/oilwell-idle.json` 保存分组与转轴，`oilwell-idle.js` 根据曲柄转角计算每个部件的位置。

`node scripts/export-fieldworks.cjs --oilwell-idle` 导出正、背两个朝向的完整循环。每个朝向有 144 帧，24 帧每秒，在 `idle/` 中分别保存底图和染色层。帧序号从 0 开始，最后一帧接回第一帧。

需要重新制作验收视频时，可将 `GREYHAVEN_IDLE_REVIEW_FRAMES` 指向临时目录，导出同屏验收图的逐帧 PNG。验收图同时展示放大近景和战场默认比例。
