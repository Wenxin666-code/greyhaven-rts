# 战场动画 v06 · 本地开发版

使用当前验收的 buildings-v05 几何和部队图集，保持地格尺度、碰撞、阵营染色及等距相机。没有接入旧 animation-v01 里的单位造型。未提交、未上传 GitHub。

## 本轮完成

1. **施工**：七类可建造建筑各 24 帧，从底板、支架、主体到屋顶设备；伴随施工粉尘、焊接火花和完成反馈。动画直接读取实际建造进度，不改变耗时。阴影、点选、血条与白色集火反馈读取当前帧。
2. **开火**：步枪、反装甲武器、步战车机炮、坦克炮、自行炮与防御阵地拥有对应枪口定位；短闪光、轻微后坐震动、曳光残影与命中效果区分轻重武器、人员与硬目标。枪口采用与本体相同的方向量化。
3. **损毁**：七类建筑各 16 帧、1.2 秒坍塌；分段爆炸、碎片、烟尘后保留原残骸。未完成建筑倒塌时只撤掉已造出的构件。人员沿用原多阶段倒地，补充小范围落地尘；车辆补充爆炸、碎片和残骸烟。
4. **工作反馈**：低于 45% 耐久冒烟、低于 25% 增加小火焰；工兵维修有火花；车辆实际移动及矿车采矿产生扬尘；生产建筑有工作提示灯。沿用精炼厂输送循环和车辆工厂卷帘门动画。

步兵移动的轻微起伏改为跟随实际行进距离，受阻静止时不继续原地跳动。这一轮没有增加完整的人体骨骼步态、独立炮管机械后坐、物理弹道或音效；轻微整车震动不等同于炮管动画。这些可以沿当前模型继续细化。

## 玩法与呈现边界

- 伤害仍按原命中时刻即时结算，射速、伤害、射程、建造耗时、经济和路径规则保持。曳光是短暂残影，不是假装有飞行时间却提前造成伤害的炮弹。
- 特效不使用游戏随机数，也不改变碰撞和地基。烟火不作为遮挡视野或造成额外伤害的实体。
- 独立视觉时钟随游戏暂停。胜负产生后，玩法停止；视觉继续收尾，1.35 秒后显示结算面板，避免最后一次爆炸冻结。最多收尾 6 秒。
- 命中与枪口受现有探索视野约束；大部分实体特效随主体深度绘制，血条独立在上层。曳光是独立短时覆盖层，不提供弹道遮挡模拟。
- 事件最多保留 256 条；缩放后的精灵缓存保持 64 MiB，满时淘汰旧帧。图集和阴影源图另占内存，该数字不是进程总内存。

## 文件与重建

- `../buildings-v05/animation.js`：由既有几何生成施工和坍塌姿态。
- `../buildings-v05/bake.js`：与静态模型一致的材质、灯光、1024 渲染和 320 输出。最后一帧直接复用规范静态图，消除切换闪动。
- `packed/anim-*.png`：每行 8 格，本体与灰度染色层分开；施工 3 行，坍塌 2 行。
- `building-audit.json`：七类建筑的 560 个本体／染色帧检测结果。
- `../../../src/BattleAnimation.cs`：建筑状态和轻微开火震动。
- `../../../src/BattleEffects.cs`：程序生成的火光、烟尘、火花图集及战场分层绘制。
- `../../../src/CombatPresentation.cs`：射击事件和独立视觉时钟。
- 修改前源码及相关脚本归档在 `../../archive/animation-before-v06-20261106/source.zip`，校验见同目录 `manifest.json`。

项目根目录执行：

```powershell
$env:PLAYWRIGHT_MODULE = Join-Path $PWD '.cache/art-tools/node_modules/playwright'
node scripts/export-building-animation.cjs
./scripts/build.ps1 -Test -AnimationPreview -MeasureScroll
```

导出可在命令后指定建筑键名。修改建筑静态模型后，先重建 v05 静态图，再重建动画。视频导出需要 ffmpeg 在 PATH 中，或用 `GREYHAVEN_FFMPEG` 指定路径。运行游戏不依赖这些制作工具。

## 验收

[19 秒原生渲染演示](../../../docs/建造开火损毁-v06.mp4)依次展示施工、开火和损毁。施工进度为演示加速，武器按各自既有射击间隔触发；场景经过摆放，不是完整战役录像。截图、视频和实际游戏共用渲染与事件代码。

新增检查覆盖施工／坍塌端点与静态图一致、未完成建筑损毁、即时伤害和命中事件同步、胜负后的视觉收尾、迷雾内外效果，以及 48 单位每秒 48 次开火并同时施工时的缓存边界。既有教程、经济、路径、阵营换色、选择和界面回归检查继续执行。原始运行记录在 `.cache/animation-v06-final-checks.log`；最终微调复核见 `.cache/animation-v06-review-final.log`。

本机完整回归通过；密集特效场景首轮离屏绘制中位 4.12 ms、95 分位 16.81 ms，精灵缓存 22.9 MiB。窗口滚屏检查在三个倍率约 63～64 次绘制／秒，最高倍率单次最大间隔 34.2 ms。这些是固定测试场景的本机测量，不保证所有机器和无限数量单位都达到同一速度，也不把离屏计时换算成实际游戏帧率。
