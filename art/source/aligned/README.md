# 等距投影校准 · v0.4.0

战场地面坐标的投影增量是 (0.87, 0.435) 与 (−0.87, 0.435)。两条轴相对屏幕水平线为 ±26.565°，对应正交相机水平偏航 45°、俯角 30°。车辆朝向按同一投影采样。方形地块在屏幕上呈 2:1 菱形，4×3 等矩形占地保留各自的边长。

**建筑。** 从上一轮的详细蓝本标注可见底板的左、前、右接点，并以屋檐、垂直立面、塔台高度构成带纹理的几何面。320 像素图格中，主体地面中心为 (160,220)，占地横跨 224 像素。安装时按逻辑占地换算绘制宽度。台阶和坡道在主体外可见，游戏的工厂出口另有预留。废墟以同一底板尺寸重新投影。

**车辆。** 标记每个原画视角的前轴、后轴和横向接地宽度，将纹理还原到车身坐标，再投影到每 22.5° 一个方向的图格。炮管的炮尾和炮口独立约束，图格留白防止炮口被截。蓝红两套共用接地中心。行驶和卡面用彩绘投影，报废用同镜头的残骸模型。原画是绘画，细部在方向帧之间仍可能变化。

**新增图像。** `support-cardinals.png` 由内置 image_gen 工具以上一版 `../isometric/support.png` 为设计参考绘制。提示词要求两行四列的透明正交方向稿，上行为带黄色折叠吊臂的六轮工程车，下行为履带自行火炮；各列依次呈现正前、向右正侧、正后、向左正侧，固定俯角、保留蓝色识别纹和原画做旧金属。工具输出经过接地标定后才进入游戏。

## 重新导出

1. 项目根目录执行 `python art/source/aligned/layout.py`、`python art/source/aligned/pack_support.py`、`python art/source/aligned/vehicles.py`。需要 Pillow、NumPy、SciPy。
2. 用本地静态服务器打开 `art/source/aligned/bake.html`。在下拉框选择建筑或车辆，导出对应 `iso-*.png`，存放到同目录的 `packed`。浏览器图形后端在此步绘制材质网格和残骸，游戏运行时直接读取预制图集。
3. 使用 `./scripts/build.ps1 -Test` 构建单文件程序，重新运行战役、界面和角度验证。游戏美术以外的目录保留早期蓝本供比对。

## v0.5.0 主战坦克
当前坦克导出使用 tank-drive.js，同一个刚性底盘逐帧转向，车体各表面分别从原画取样。每阵营 64 帧，每格 192 像素，共三组（含残骸）。中间角度仅代表转动。tank-bearing-check.csv 保存导出器对同一套模型的炮口与炮尾像素质心测量，窗口测试把测量方向与真实屏幕轨迹对照。
