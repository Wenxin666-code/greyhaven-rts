# 灰港等距战场 · 素材制作记录
本版直接从首轮透明蓝本 `../v01/base.png` 提取指挥部、电站与工厂。其他彩稿用内置图像生成工具绘制，实际游戏使用 `packed` 中带透明通道和阵营色的 PNG。地面通过引擎按逻辑坐标铺设，草地与海岸等材质不包含预画建筑。

| 原稿 | 参考与绘制要求 |
| --- | --- |
| ground.png | 2×2 平面材质。海岸草甸、旧混凝土、蓝绿海水、沥青各占一格，仅有地表纹理 |
| buildings.png | 以首轮建筑为样式蓝本，双排兵营、碟形雷达、双管防御阵地。统一蓝灰屋顶、混凝土底座、斜俯视光照 |
| objectives.png | 同系列的仓库、带装卸吊架的转运站、带观察室的港务塔，分别对应占领与守港目标 |
| ifv.png、tank.png | 以首轮八轮步战车、履带主战坦克为蓝本，固定镜头下分别绘制车身朝向；坦克额外执行一轮去除棚拍白底 |
| troopers.png | 在同一镜头画步枪兵、肩扛发射筒的反装甲兵、黄盔工具箱工程兵，各有四个方向 |
| support.png | 双排方向稿。工程车带折叠吊臂，履带火炮带长身管和尾部驻锄 |

运行 `python scripts/pack-field-art.py` 可重新裁切和打包，需 Pillow、NumPy、SciPy。每格 256 像素；车辆朝向按实际炮口与车头复核并重排，红方只转换识别色。原稿是绘画帧，近距离逐帧查看会有局部差异。程序独立嵌入生成图集与地面材质，旧模型继续用于倒地和残骸。
