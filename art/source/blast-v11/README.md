# 建筑爆炸与独立弹片 V11

本轮只更新本地。V10 和更早的图像、模型与录像继续保留。

烟火由内置 `image_gen` 工具生成，原图为 6 × 4 格、24 帧的透明 PNG。源图未修改；运行图集通过带透明度的缩放、裁切和预乘色插值扩为 96 帧，末尾平滑消散。检查后的原点为每格 `(128,238)`。这是本项目的新素材，外部游戏画面只作观察参考。

弹片分为金属折板、混凝土块、弯曲构件和设备碎块四种可辨轮廓。每种保留 8 个朝向和 32 个三维翻转姿态，共 1024 格。金属与设备的部分表面支持任意势力色，中性断面、灰尘和烟火不随势力改变。轮廓由可编辑几何生成，源模型在 `src/BlastArtV11.cs`。

每块弹片有独立起点、延迟、喷射速度、水平阻力、重力、旋转速度与落地时刻。较重碎块与薄板使用不同反弹系数；少量碎块带烟尾，落地有短暂尘土或火花。细小余烬使用独立轨迹。所有运动由时间直接取样，不使用游戏的随机数、不生成战斗单位，不改变伤害、经济、单位碰撞或寻路。

正常完整建筑约有 10–12 块明显碎片，加少量细火星；半成品相应减少。当前检查中最长碎片存在约 1.16 秒，随后完全清除。建筑爆炸后只保留装饰弹坑，地面阴影随弹片一起结束。弹坑不占格、不挡路，重建时位于建筑下面。

火球、烟团、弹片前后层、地面投影与接地扬尘分开绘制。彩色碎片小图最多 1280 张（20 MiB），烟火裁切帧最多 32 张（4.5 MiB），共用的显示缓存继续限制在 64 MiB。关闭窗口释放这些图像。

`scripts/build.ps1 -BlastVerify` 检查轨迹、三维姿态、任意染色、正常缩放辨识度、清理与缓存上限。`-BlastPreview` 另导出实际原生窗口录像；需要 `GREYHAVEN_FFMPEG` 指向 ffmpeg。重新绘制几何／重新打包图集时设置 `GREYHAVEN_REBAKE_V11=1`，执行 `-BlastPreview`，将 docs 下对应三张 PNG 保存到本目录后重新构建。原生游戏读取内嵌图集，不使用网页。

本轮已通过弹片专项、既有建筑受损／清理专项和原生界面操作检查。上一次完整玩法回归记录仍独立保存在 `.cache/structure-v10-final-regression.log`，不将其冒充本轮的新专项结果。

参考：[红警 2 原生游戏爆炸实录 7:41–7:42](https://www.youtube.com/watch?v=E7X9pT4AMu8&t=461s)，逐帧观察了火球转烟、烟外碎片和落地过程；[OpenRA 的独立碎片说明](https://docs.openra.net/en/release/traits/#fireprojectilesondeath) 为重制实现的设计参考，本项目没有采用其碎片伤害逻辑。
