# 灰港演练场 · 第二轮素材
2026-11-04。打开 [离线验收入口](../../review/index.html) 可在战场使用实物；[上一轮原画](../../review/v01.html) 可比对轮廓和用色。

## 现场操作
- 直接点选地图上的单位或在检阅栏选择，点击空地行进。选中环和行军虚线指出对象与目的地。名称标注可关闭。建筑占地、水面、货柜、北侧小屋与吊机限制通行。
- 检阅角度有十六档，可连续播放。滑杆独立于战场朝向。车辆在地图上移动时沿同一组方向帧转向，建筑部署时使用滑杆所选朝向。
- 海蓝、砖红、琥珀分别作用于装甲板、头盔识别区和建筑饰带。地图另设圆、菱、方三种徽标帮助辨认。切换涂装用于验收，双方都可操作。
- 从一座完好的车辆工厂选择车型、下达出车指令。卷门抬起，车辆从正门驶到集结点后可以独立选择。出口堵塞时需先移开部队。选择建筑可在西南水泥坪试放同型建筑。
- 损毁可逐项预览。步兵跌倒，装甲车留下歪斜炮塔、脱落部件，建筑留下对应废墟。复原或重置演练可重复检查。

## 资源结构
`models.js` 描述六种母模、固定几何、局部涂装和状态。`bake.html` 使用随附的 Three.js r160 离线渲染到透明 PNG。修改母模后打开导出页，选择对象并将下载的图集放回 `sprites`。日常打开演练场只加载二维图集。
每格 192 × 192 像素，每行 8 格，两行共 16 朝向。0 朝屏幕下，编号沿屏幕右侧旋转；步兵、轮式步战车、履带坦克、指挥部、电站、工厂分别独立导出。

| 图集 | 自上而下的方向组 |
| --- | --- |
| ifv、tank、hq、power | 蓝常态、红常态、琥珀常态、公共残骸 |
| squad | 各阵营依次为站立与迈步，共六组；随后是公共倒地终态，再接三色失衡中间姿态 |
| factory | 各阵营依次为关门与开门，共六组；随后是公共废墟，再接三色半开门姿态 |

单个对象的尺寸和投影固定，旋转时由同一母模和相机重新采样。首轮的八轮底盘、长炮履带、通信桅杆、双烟筒和卷门沿用。二代模型的面数和贴面细节较首轮概念稿简化。当前可验收方向、地面可读性与关键状态。完整战役、生产经济、战斗判定与拥挤部队之间的相互避让属于后续原型。

## 地图原画与参考
`port.png` 是内置图像生成工具绘制的原创空地形。首轮绘图要求为正交俯视的沿海港区，北面水域，东西公路和南北引道相交，西南预留混凝土基地坪，右上布置中立货柜和吊机。第二次在同一底图上保留路口与海堤位置，单独补画草地便道、两间低矮工具房与水箱。可控物体均另外绘制，场景与地图障碍在同一逻辑坐标系中对齐。
