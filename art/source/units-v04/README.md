## 文件与生成

- `models.js`：独立可编辑几何源模型与尺寸规格，前进方向 +Z，地面锚点为原点。
- `models/*.json`：Three.js ObjectLoader 可读取的场景、几何与材质。
- `packed/*-base.png`、`*-paint.png`：中性本体与灰度势力涂装层。
- `packed/*-wreck.png`：车辆残骸；步兵倒地仍由游戏同步处理两层。
- `audit.json`：逐方向不透明区域边界检查。

模型使用已确认坦克的中性涂层及光照。步兵 8 方向、其他车辆 16 方向；全部由 1024 像素源渲染抗锯齿缩至 512 像素单格，坦克仍使用原有 64 方向素材。增加源清晰度不改变游戏中的单位大小、接地点、碰撞体积、速度与作战数值。

中性本体和势力涂装分层，运行时支持任意势力编号与 RGB；布料曲面保留平滑法线。皮肤、玻璃、金属、矿石、工具等不染色。矿车点选与集火闪白同步使用实际空/满载轮廓。

在项目根目录设置 `PLAYWRIGHT_MODULE` 指向已安装的 Playwright，机器需安装 Microsoft Edge：

```powershell
node scripts/export-unit-models.cjs
# 可选：只重建某个单位
node scripts/export-unit-models.cjs ifv
./scripts/build.ps1 -Test -ModelPreview
```

导出工具仅在制作时使用浏览器，游戏本身仍为离线 Windows 单文件程序。`--revision=03` 可指定重建保留的旧模型，默认重建 v04；历史素材不会被当前导出覆盖。已有图集时，构建不需要重新导出。

旧版 `units-v03` 原文件保留并标记停用，第一版压缩归档也保留。`art/review/animation-v01` 继续只保存，不接入游戏。

## 本轮验证

`-Test -ModelPreview` 全部通过：完整教程、两种战役、20 车绕障、六矿车共厂交货、点选与指令、预览单位切换、任意颜色及缓存、全部步兵倒地方向。新图集共 288 个分层方向视图通过非空和边界检查；满载矿石在 16 方向共 4083 个采样点通过点选与中性色隔离检查。坦克原有 64 朝向涂装检查及八方向实际行驶投影检查继续通过。

本轮未以提高帧率为目标。模型仍预渲染并复用原有缩放缓存，不在运行时绘制几何体；1024 源渲染的成本发生在素材导出阶段。更高分辨率图集会增加素材内存，不能据此宣称性能提升。离屏对照的 24 辆坦克场景中位 43.82 ms、95% 52.67 ms，仅供本机后续对照。

## 后续细化 · 2026-11-06

当前人物进一步细化：共享确定性织物纹理与低强度凹凸，背心缝边、弹匣袋、背包分层、头盔通讯设备；重装兵增加护面和发射器结构，工兵保留黄盔并增加帽灯、工具锁扣和小仪表。服装、装备的主要轮廓与原占地保持，未改速度、碰撞、人体身高、源镜头宽度或运行时单位尺寸。

三类步兵共 48 张分层方向图通过非空／边界检查；染色掩码占不透明面积约为步枪兵 21%～26%、反装甲兵 14%～22%、工兵 19%～27%（逐朝向不同，阈值为 alpha>80）。胸背、肩臂、部分护具可染色，肤色、武器、工具保持中性。新增细节使步枪兵侧向背包边缘在 512 像素源图上最多增加 4 像素，其余两类外接边界不变；三类高度不变，不改变单位的显示倍率或占地。

默认战场镜头独立从 1.05 调为 1.55，即同窗口下所有地图对象线性放大约 48%，仍能滚轮调整；地图世界尺寸与相对比例不变。源渲染仍在离线导出阶段完成，游戏继续使用预渲染图层和缓存。旧人物源模型、图集、导出模型、审计和预览保存在 `art/archive/infantry-before-detail-20261106`。

## 人物写实化调整 · 2026-11-06

将膨胀的椭球背心改为贴合胸腹的携板背心和侧腰围带。轻装兵、工兵使用布袖与肩部缝线；反装甲兵保留宽肩识别，但以薄的分层护具代替圆球护甲。膝具和靴头更贴合人体，保留旧鞋底范围与接地点；面部耳、颊、鼻和嘴部收敛，头盔补充布罩缝线、导轨固定件与后部束带。

人物布料与复合护甲单独降低金属反光，不改变载具材质。颜色分层仍独立，胸背、肩臂和部分护具可任意换色，肤色、黄盔、武器、工具保持中性。三兵种的模型身高与显示倍率保持；收窄鞋头后，部分斜向的透明边界测量高度减少 1～3 个源像素（512 像素单帧，人物可见高度约 340 像素，变化不足 1%），并未拉伸图集补齐旧矩形鞋头。地图占地、碰撞、站位和作战数值没有改动；局部外轮廓会因衣甲贴合而变化，并非放大模型。染色掩码／不透明面积：步枪兵约 21%～26%、反装甲兵约 14%～22%、工兵约 19%～26%，各方向均有可见色块。

本轮前的文件保存于 `art/archive/infantry-before-realism-20261106`，包括可编辑源模型、导出模型、分层方向图、审计和对照图。当前效果仍见上面的三兵种及八方向链接。

本轮验证：完整模拟和窗口回归通过；最后一次鞋型／肩甲调整后，重新导出 48 张分层朝向并运行模型与画面检查，八方向非空、换色隔离、倒地、单兵点选、显示比例验证通过。已检查实际嵌入素材的近景和局内尺寸预览。未提交或上传 GitHub。

## 人物轮廓棱角化 · 2026-11-06

服装的横截面改为具有正面、侧面和窄切角的八段轮廓，侧棱拆分法线，纵向继续保留细化褶皱；没有降低纹理或输出分辨率。头盔由球顶改成平顶和倾斜侧面，帽沿同步切角，阵营色条贴在新顶面；护甲和布包使用窄直线倒角，肩部以薄切角护片收出清晰轮廓。
