# 旧港船只与港区设施

第一章《断线之夜》使用这套等距素材。可编辑的几何、材质、铰链和动画位于 `model.js`。`bake.js` 使用游戏的地格投影与现有建筑材质烘焙透明图层。

| 素材 | 地格与动作 |
|---|---|
| 浅滩登陆艇 | 约 4.8 × 2.0 格的船体，车辆甲板留空，前跳板独立转动 |
| 港区补给船 | 约 9.2 × 2.9 格的船体，保留 0° 到 90° 的靠离泊朝向 |
| 港务中心 | 2 × 2 格地基，调度窗和屋顶灯对应供电状态 |
| 码头吊机 | 塔身落在泊位，吊臂、吊索和货箱按一个装卸周期运动 |
| 货运闸 | 两扇铰接闸臂对应现有六格宽公路，通行状态由关卡控制 |

船体、侧板和选定设施面板有独立的阵营色贡献层。玻璃、金属、货箱及安全警示条采用本体材质。正式运行只读取嵌入的 `packed/harbor-v01.pak`，玩家电脑无需浏览器渲染环境。

在项目根目录使用本机 Playwright 和 Edge 运行 `node scripts/export-harbor.cjs`，再用带 Pillow 的 Python 运行 `python scripts/pack-harbor.py`。导出器可通过 `PLAYWRIGHT_MODULE` 指定 Playwright 目录。打包器会重建素材包、画面定位参数和[验收图](review/港区素材.png)。`frames` 是可重建的中间文件。
