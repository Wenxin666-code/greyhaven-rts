# 步兵与碉堡素材

原生可编辑 Three.js 几何，延续 units-v04 与 buildings-v09 的材质、光照和投影。
没有复制第三方游戏贴图。旧素材与历史归档保留。

- 狙击手：8 向站立、8×12 关节行走；长枪、短披肩、独立可染色胸背与肩部。
- 反装甲兵：新收起姿态携带机枪，发射器背负；8×12 行走。
- 步枪兵／反装甲兵：分别 8×33 同一人物、装备的连续蹲伏及阵地展开姿态；倒放收起。
- 驻兵碉堡：2×2 地基；72 帧分部施工、96 帧设备待机、3 级受损；沿用运行时燃烧、弹片和最终爆炸。
- 颜色为独立光照贡献层；使用 B−P+tint(P)，中性材质和透明轮廓保持不变。

- 三种步兵的移动、瞄准和后坐分开：5套姿态（步枪、狙击、反装甲移动、步枪部署、反装甲部署），每套8向、17帧抬枪／后坐。手臂跟随握枪位置调整；原单位模型仅增加手臂、武器部件标记，不改变旧几何；狙击枪在新模型中整体替换。
- 动画按每个方向的完整序列统一裁边，保留原相机、脚底锚点及尺度；元数据由打包生成。

导出顺序：scripts/export-infantry.cjs → scripts/export-combat.cjs → scripts/pack-infantry.py。
frames 是可再生中间文件；正式 pack 和源模型应保留。严禁用导出帧覆盖旧素材目录。

## 连续部署修订

- 狙击步枪移除旧步枪整套部件后重建，一根枪管、一套瞄准镜。weaponRole 明确指定武器；rigidEquipment 防止低持枪管被腿部动画弯曲。
- 反装甲兵始终使用 at-mobile 同一骨架和发射器：收枪到侧面 → 伸手取背部装备 → 绕肩抬起 → 双手持握。步枪兵屈膝、放下并展开携行阵地，脚底不整体下沉。收起反向执行33帧。
- 每次部署／收起1.1游戏秒。正在瞄准时先收枪，途中反向命令不重置进度；战斗终点与部署终点共用几何和手臂锚点。
- scripts/verify-infantry-rig.cjs 检查枪械刚性、逐帧反向一致、部署终点衔接和异常大位移；原生逻辑检查覆盖中途反向和先收枪。
- docs/infantry-motion-20261110 保存图示、视频和验证记录；preview-frames 为可再生文件。
