# 《断线前沿》战役主线与关卡规划

主战役暂定名 **重连灰港**。故事与关卡布局更新于 2026-11-11。

这条主线贯穿野外训练、河湾镇、孤岛要塞和雾脊中继站。四关已有对应的敌方行为、任务简报和通关衔接。第五至第八关处于设计阶段。背景、组织与人物均为虚构。

## 主线故事

灰港曾经是沿岸最繁忙的工业港。矿产从内陆运来，机械、燃料与粮食从海上进入，再通过河湾公路和北部铁路分往各地。一场持续多年的地区冲突结束后，这条运输链勉强恢复，沿岸却留下了各自掌握武装的驻防军、矿业公司和地方防卫队。停火协议让他们暂时共用道路，关于矿区、税收和驻军权限的争执始终没有解决。

随后，灰港发生了“断线之夜”。主干通信节点和港口调度先后失效，物资交接记录无法核实，互相矛盾的封路命令传遍沿岸。等待补给的部队开始扣留车队，矿业警卫接管道路，各地原本紧绷的停火线重新响起枪声。地方无线电仍然能够工作，但没有哪支部队能确认远方发生了什么，也没有人愿意先解除自己的封锁。

玩家是沿岸联合保障司令部的一名先遣指挥官。原定在灰港外港进行的野外训练，临时变成了夺取登陆点的实战。总部交给你的任务很具体：保住旧码头，打通内陆通道，让工程与补给人员重新进入灰港。你带来的只有一支能够展开基地的工程分队，必须就地采矿、整备车辆、建立防线，才能向前推进。

旧码头稳定后，你发现河湾镇的两支武装既封锁道路，也在互相争夺桥头。击败它们，只能解决眼前的交通问题。更深入的矿业盆地已经迎来五路武装，各方都在建立基地，准备靠当地资源维持长期战争。你抢先进入西北的保障岛，利用岛内矿藏和唯一的堤桥建立支点，最终取得灰港外围工业带的控制权。

接管这一带的设施后，工程官周砚发现了数份时间相互吻合的调度记录：部分封路令在通信中断前已经签发。后续在雾脊中继站恢复的日志证实，“断线”包含一场有计划的封锁行动。发起者是前联区防务总监贺峻，以及他组织的应急统辖部。他认为分散的地方权力迟早会再次引发战争，决定控制通信、能源和运输分配，迫使沿岸接受长期军事统辖。

五路地方武装各有自己的目标，彼此争夺资源；贺峻利用了这种分裂，却无法随意指挥它们。玩家面前的战争因此有两层：先击退占据道路与矿区的部队，再从统辖部手中夺回维系整个地区的基础设施。恢复一条通信线路，可以获得真实的运输消息；重启一座电站，可以让港口设备工作；送达一批维修器材，才能把这些局部胜利连接起来。

当灰港准备重新开放时，贺峻调动直属部队进攻港区。港口一旦恢复运转，各地便能够绕过他的配给系统获得物资，统辖部将失去迫使沿岸服从的筹码。先遣队必须守住已经修复的设施，并打断敌军的攻势，随后向衡岭指挥枢纽发起最后的进攻。

战役结束时，港口仍有受损的街区，军队也还在撤离。最后一段无线电来自普通的港务调度员：“灰港调度呼叫第一运输队，航道恢复，可以进港。”玩家最初抢下的小码头，终于成为一条能够正常运转的补给线的起点。

## 三关之间的连续关系

**旧码头提供登陆入口 → 河湾镇提供通路 → 资源岛提供长期作战能力。**

每次转入新地图，已经稳定的地区由后续保障部队接管，玩家率工程分队开辟新的前进基地。上一关的成果仍然影响故事，下一关依旧需要在新的作战区建立生产体系。各关开局是新战区的先遣部署，不把旧基地写成无故消失，也不要求现阶段实现跨关单位继承。

### 第一关：野外训练

剧情章名：**断线之夜**。位置：旧港滩头。

这是先遣队的第一次接触战。旧码头已被北线驻防军的一支封锁分队控制，玩家需要先保住登陆入口。开局采用现有教学流程，依次学习展开、供电、采矿、生产、选择和进攻。教学提示来自许岑的现场指引，学习内容对应维持滩头阵地的实际需要。

**现行胜利条件保持：消灭港区内全部敌方守军，按现有教程完成行动。** 不增加限时撤离、保护船只或额外占领目标。

建议通关叙事：码头交接时，一名留守人员送来断联前的运输记录。原本应抵达港口的工程车队停在河湾镇。许岑提出，必须先打通那里，否则登陆点得不到持续补给。

游戏内简报：

> 灰港的长途通信与港口调度在同一夜中断，沿岸驻军开始争抢补给。原定的野外训练紧急转为登陆行动。你带工程分队进入旧码头，在参谋许岑的引导下建立基地，击败北线驻防军的封锁分队。先保住这个入口，才能查明内陆发生了什么。

任务目标：在旧码头建立补给基地，击败封锁分队，稳住登陆入口。

### 第二关：河湾镇

剧情章名 **桥头的两面旗**。先遣队从河湾大桥西侧进入交通区。

河湾大桥是工程车队进入内陆的唯一陆路。断线后，北线驻防军河湾支队依据旧命令扣留了一支白石矿运车队，打算征用车辆和燃料。白石矿务警卫队随即封锁东岸卸货场，阻止北线转运。北线驻防军在东岸北侧展开，白石警卫队在南侧设防。两支分遣队都要控制桥头，彼此交火，也会攻击试图渡桥的先遣队。第三关出现的是两支组织留在矿业盆地的其他部队。

地图为 92×68 格，河湾大桥是两岸唯一通路。工兵可以先占桥边房屋，让步兵掩护过桥。通过桥头后，东岸公路分向两个敌方基地，玩家可以利用双方交火的间隙选择推进方向。[选关全图](../河湾镇-单桥全图.png)

**现行胜利条件保持：消灭两个敌方阵营的全部单位与建筑，或迫使其投降。** “打通运输线”是击败封锁部队后的叙事结果，当前没有隐含的车队护送判定。

建议通关叙事：河湾的道路重新开放。工程车队留下的施工图表明，西北保障岛仍可作为前进基地；与此同时，侦察消息显示，多路武装正向相邻的矿业盆地推进。先遣队必须抢先建立支点。

游戏内简报：

> 旧码头已由后续部队接管，工程车队却停在河湾。断线后，北线驻防军扣下白石的矿运车队，白石警卫队随即封锁东岸卸货场。两支武装都在东岸争夺桥头。我方从西岸展开，夺过唯一的大桥，打通通往内陆资源岛的公路。

从西岸渡桥，击败东岸两支武装，打通通往工业带的公路。

### 第三关：孤岛要塞

剧情章名：**五路烽火**。位置：西北资源岛与大陆矿业盆地。

先遣队经河湾通道抵达撤空的保障岛。岛内富矿适合扩军，唯一堤桥也限制出击与增援。停火时期，各方共用盆地的装卸站和铁路。灰港停摆后，北线要征用运输，白石要保住矿料，铁轨卫队扣住车皮争夺调度权。南岸防卫队封闭辖区道路，挡下未经许可的车队。边境独立旅缺少固定补给，袭扰附近矿路。各方控制的环节互相牵制，临时交火演变为各自设防的混战。

这一关是前三关的综合考验：经营多条生产线、维持岛口守备、控制出击规模，并逐步把部队和生产能力推向大陆。资源岛矿藏有限，故事不将其描写成永不枯竭的安全区。

**现行胜利条件保持：消灭五个敌方阵营的全部单位与建筑，或迫使其投降。** 当前六方开局、基地位置、富矿和唯一堤桥均保留。首个被击败的敌方和最后的对手可以每局不同，不安排按剧情时间自动淘汰的阵营。

建议通关叙事：五路武装退出盆地后，周砚在接管设施时汇总了各处调度记录，发现封路令早于通信故障。证据需要到雾脊中继站核对。此时玩家建立的是反攻支点；灰港深处的统辖部及其封锁系统仍然存在。

游戏内简报：

> 越过河湾后，你先一步抵达西北资源岛。五路武装正从大陆各处进驻矿业盆地，各自采矿扩军，互不服从。岛内富矿可支撑反攻，唯一堤桥也会把战火引来。守住入口、击败五方，建立能够长期支撑内陆行动的基地；灰港失联的原因仍未查明。

任务目标：守住资源岛入口，击败大陆五支武装，建立内陆反攻支点。

上述通关衔接已以结算短文接入，保留用时和存活部队统计；没有新增过场配音或跨关部队继承。游戏内简报也已按实际行为调整，第二关的桥头警戒须由敌方正常发展并派兵建立，不声称开局已部署完整桥头阵地。

## 后续五关的制作方向

### 04 雾脊中继站

中继站需累计恢复 360 游戏秒。失守会暂停恢复并保留进度。首次达到 50% 时，仍在抵抗的敌方获得一次性 7500 经费，玩家收到通报。[第四关设计稿](第四关-雾脊中继站.md)

统辖部占据中继站，阻止外界核对调度记录。玩家已有岛上保障基地作为后方，需要在山脚建立小型前进基地，打通上山道路，派工兵进入中继站。山脊提供一条适合车辆的主要通路和一条可供小部队绕行的侧路，避免所有单位只能挤在同一个出口。

新增核心机制为**任务设施的占领与恢复**：工兵按现有规则进入并消耗，设施归属改变后开始可见的恢复进度，敌军重新占领时暂停。玩家守住设施完成恢复即获胜，无需清空整张地图。中继站被摧毁即任务失败，开局须明确标识并提醒保护。日志在关后确认贺峻的命令，区域军事通信恢复；港口完整调度仍需电力和设备。

### 05 石门电站

中继站确认港口主供电来自石门。统辖部一面控制电站，一面利用外围配电设施维持自己的防御。玩家需要保持主电站完整，先消灭守军再派工兵接管；可以强攻，也可以夺取外围配电节点，削弱对应防区后推进。

新增核心机制为**本关固定设施之间的供电联系**，只作用于标明的任务设施和防区；常规玩家电站与基地用电规则保持统一。两岸道路、坝顶通路和工业院落要支持不同突破方向。完成接管后启动电站，摧毁主电站即失败。结尾说明港口已有电力，但维修器材仍滞留在内陆。

### 06 长桥运输线

恢复后的通信与电力必须配合设备，才能重新开放港口。三批关键载荷需要通过长桥运输线。玩家建立路侧基地，清理桥头与城镇火力点，自行决定何时派车以及走哪条可用路线，利用工兵维修车维持护送部队。

新增核心机制为**可指挥的任务车队与交付记录**。战区内同时活动的任务车队最多一支，避免迫使玩家在多个远处地点连续操作。货物送达后计入进度；损失车辆后可以付费重新组织尚未送达的一批，重试成本清楚显示。目标为送达三批载荷，敌方补充兵力沿用真实基地与生产。道路通畅与侧翼控制直接影响运输，不靠隐藏时间点让车队突然冲入敌阵。

### 07 灰港围城

贺峻得知港口将重新开放，派直属军沿铁路与外围公路进攻。玩家回到已经建立保障体系的灰港，以有限的预置基地守住港口维修区，保护恢复成果。相比第三关的单一堤桥，本关有多个可相互支援的陆路入口，要求预留机动力量。

新增核心机制为**分阶段防守与修复进度**。任务窗口显示抢修进度与当前受威胁方向；敌军从地图上真实生产设施组织攻势。摧毁其前进工厂、打击矿车和运输通路会降低后续压力。完成抢修并击退仍在港区内的进攻部队后获胜，港口主调度设施毁坏则失败。关后各地能够收到经核实的指令与运输安排，统辖部的封锁出现缺口，但其直属军仍需在最终战役中击败。

### 08 衡岭枢纽

衡岭掌握通往内陆的最后一组道路、铁路与指挥节点。统辖部退守此地，试图把沿岸重新封闭。地图包含可独立攻取的外围生产区、配电区和交通节点，玩家自行安排突破顺序，逐步把前进基地推进到主防线附近。

本关复用前面学会的占领、供电、驻防、护送与基地经营，不再叠加新的经济体系。外围打击产生具体效果，例如减少装甲增援或使一段固定防区失去供电；路径必须提前规划，不能因关键设施被毁而形成无法通关的死局。最终条件是击败或迫降统辖部直属军，并由工兵占领保持完整的主控设施。港口恢复通航作为结局，后续战役可从新的地区与战争后果展开。

## 关卡设计约束

1. **地形必须对应作战选择。** 每个主要区域要说明它影响的是经济、通路、视野还是阵地；海水、沙滩、陆地和坡道仍为真实地格。战场覆盖完整雷达投影范围，海岸随地格与地理关系组织。高地、湿地等尚未实现的属性不能只靠简报声称生效。
2. **保持当前的资源与生产基础。** 矿石运回精炼厂后获得采购军费；野战工厂的短周期生产是整备与组装的游戏抽象。敌军依然需要采矿、付费建设和生产，不用剧情无限刷兵取代经济。矿产可耗尽，不恢复占仓库自动加钱的机制。
3. **把大规模交战与集中任务交替安排。** 第三关强调六方经营；第四关集中在设施夺控；后续通过地形、任务和进攻方向变化提升难度。控制活跃部队与同时触发事件的规模，避免用地图面积和堆兵数量单独制造难度。
4. **让工兵、步兵和车辆各有作用。** 夺控需要工兵，房屋与街区需要步兵，装甲承担机动与正面交战，火炮用于阵地攻坚。任务设施的入口、驻防出口和车辆通道必须在地图阶段留出空间，并有实际可达路线。
5. **尊重战斗的不确定性。** 固定的是故事阶段与任务理由，进攻顺序、阵营发展、战损和突破路线由对局决定。第三关的五路武装始终维持各自敌对关系，不能为剧情突然联合只打玩家，也不指定某方必须在某分钟覆灭。
6. **目标要能读懂，也要能结束。** 前三关维持现有胜利判定；后续每关增加一个主要目标系统。必须保全的任务建筑清楚标记，关键设施毁坏、载荷损失和无法继续行动时给出明确结果或重试方式。任何新任务系统正式制作前，先明确完成与失败条件。
7. **叙事遵守当前功能边界。** 局部无线电和玩家雷达仍然有效；“断线”指跨地区主干通信、调度和组织失效。雷达不因故事获得全图扫描能力，间谍卫星按现有规则使用。中立房屋视为已撤空建筑，保留工兵先占领、步兵再驻防的流程；当前不虚构已经存在的平民救援系统。
8. **主线不强迫持续阅读。** 开场简报交代来由与目标，战中无线电每次一两句，同一触发只出现一次；通关短文承担下一关的过渡。首次收到资料、占领设施等事件随真实行动触发。长篇背景放在可选档案中，战斗中不连续弹出遮挡地图的剧情窗口。

## 建议制作顺序

八关主线与五路武装身份已建立。前三关已补充对应行为和通关过渡，第四关已具备任务进度窗口。

第四关《雾脊中继站》的工兵夺控、进度暂停／恢复、目标建筑损毁失败流程已接入。后续用同一任务设施框架扩展第五关供电节点和第八关主控设施。第六关的运输任务需要单独处理车辆路径、堵路重试与载荷交付；第七关再复用前三关的真实经济、基地防守与进攻编组。

旧《初步策划》继续作为历史构想保留；叙事发展以本稿为讨论基础，现行可玩规则以游戏实现和当前 README 为准。

## 2026-11-09 敌方行为与故事对齐

### 调整原因与范围

修改前，第二、三关主要使用同一套生产、选敌和出击规则，五方的身份尚未体现在行动里。另有两个实际阻碍：便宜步兵持续消耗可用预算，部分车辆工厂长期造不出核心战车；所有余兵优先进入进攻队，路口驻防无法形成。第一关的单个教学守军也没有明确的守点命令。

各方先填补基地守备，再按身份调动正常生产的部队。第四关的「统辖部半程拨款」由中继站恢复进度触发。

| 关卡／势力 | 本地已实现的行动 |
|---|---|
| 第一关封锁哨兵 | 围绕旧码头原位置警戒，在警戒范围内接战并返回岗位；不追到玩家登陆基地，也不追加教学阶段的经济或增援波次 |
| 第二关北线驻防军 | 扩军后派四人分队守东岸桥头北侧。主力偏装甲，重视敌方生产设施。基地受袭时外派分队返回 |
| 第二关白石警卫队 | 扩军后警戒东岸桥头南侧。较早考虑第二精炼厂，重视矿运设施的守备与维修 |
| 第三关北线驻防军 | 偏重坦克编成，守交通线，主力整队推进；确有装甲后适度释放步兵守备名额 |
| 第三关白石警卫队 | 防守矿区和精炼厂外缘，附近矿运设施受袭时提高反击优先级；经济受损仍可能被击败 |
| 第三关铁轨运输卫队 | 偏好机动战车、小队与较短的侦扰间隔，派分队控制邻近河道通路 |
| 第三关南岸防卫队 | 更早考虑第二兵营，分队向附近城镇推进；工兵按原规则占房后，外派步兵可转入驻防，最多六名、每屋最多三名 |
| 第三关边境独立旅 | 偏机动袭扰，优先已知且防守较弱的矿车／精炼厂；设前沿警戒点，并在合法相邻建造范围内偏向前方布置后续生产设施 |

这些是偏好，不是固定剧本。发现较强防御阵地后，各方仍会提高火炮比例；资源不足、基地受袭、没有足够部队或道路受阻时不会强制完成外派。五方继续互相敌对，选敌仍考虑距离、已知威胁和正在遭受的攻击，没有联合只打玩家的分支。

### 守备、生产与情报规则

- 基地守军、四人路口分队、主攻队和侦扰队不会重复占用同一单位。分队从实际余兵中选出，原有兵力不足就等待生产。
- 基础守备仍从六名开始，成熟基地按来敌方向保留十二／二十名。北线部队只有在已有真实战斗车辆时，才每辆抵一个名额，最多减少四个；没有车辆时不减少。已有敌人接近基地时不会释放现有守军。
- 外派分队避开道路、矿格和厂门，抵达后警戒。总部／工厂受袭、分队损失至少一半、已知敌军明显占优或长期未抵达，会撤回整编。不同势力的主攻队撤退阈值也有差异。
- 为核心车辆编成保留正常采购预算，防止步兵持续抢光资金。单位仍通过工厂队列按原有时间出厂，建造和维修仍正常扣款，不修改价格或速度。
- 白石与南岸的侦扰更偏反击，铁轨与独立旅更主动。两类部队的出击都受守备与实际余兵约束。
- 阵营信息页显示组织名称和偏好。玩家首次在已探索区域发现某方单位时，许岑给出一次简短说明；消息保留十四游戏秒，不被普通生产消息覆盖。不因此揭开地图或读取未探索的敌军位置。
- 前三关结算分别指向河湾、资源岛和雾脊中继站；第四关继续确认贺峻并指向石门电站。
