# 地图地格与建造提示规范

2026-11-08，随 v0.20.0 发布。按用户要求，取消格内曲线海岸，本轮不执行冒烟测试。

## 地图范围

战场以完整雷达投影范围为准：`u=x-y`、`v=x+y`。旧的陆地矩形仅是历史布局的坐标参考，不是陆地边界。范围内的格子均有实际地形，陆地可以延伸至原坐标矩形以外，不能用装饰海水填充没有地形数据的角落。

相机、雷达、迷雾、建筑放置与寻路使用同一战场范围。今后新增地图也应先确定雷达覆盖域，再安排海陆、出入口、出生点、矿区与中立建筑。

## 每格一个地形

- 地格仍为 24 世界单位，显示为完整斜视地格；单格只能是一种地形。
- `Water` 是完整水格，目前陆上单位和建筑不可通过、不可放置。保留水格坐标供以后水上建筑、舰船、港口规则使用，本次不提前开放这些功能。
- `Sand` 是独立沙滩地形，与海水分开；平坦、无障碍且满足扩建与探索条件时，按陆地规则通行、建造。
- 草地、沙滩和海水均整格绘制，不使用格内水陆插值、多边形切片、贝塞尔曲线或装饰遮罩改变岸线。
- 岸线的转折来自相邻地格的分类。地形生成可用距离场选择地格，但最终只保存和使用每格的地形类型；没有半格海水、半格陆地。
- 旧有道路、桥梁、坡道、高地、矿区和建筑仍有各自含义。第三关资源岛保留唯一堤桥，各方出生点和房屋布局沿用现有设计。

`RiverbendMap.At` 同时提供核心区及雷达覆盖域内扩展区的地格。地图导出中的 `radarTerrain` 保存完整范围、地形图例以及每格坐标、地形、高度和树木状态；旧 `cells` 仅为旧预览工具兼容字段。

## 建造预览

每个地基格独立检查，受阻格红色、可用格绿色；一格不合格不会让其他地格一同判为地形受阻。实际放置调用同一检查结果，避免预览与落地规则不同。

阻挡原因包括水域、树木、桥梁、坡道、地面高差、建筑、单位、未采完矿石、墙体、未探索和超出战区。高差以地基内可用格的主要高度为准，标红不在同一高度的格子。缺少已展开基地或整体超出扩建范围时，整块地基不可放置，并明确显示整体原因。

提示只在放置时出现，不新增常驻操作说明按钮。不改变单位碰撞、建筑占格、美术比例及其他生产规则。
