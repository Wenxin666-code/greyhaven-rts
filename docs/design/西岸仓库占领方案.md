# 西岸仓库 · 前线抢修点（待定方案）

建议保留现有步兵占领规则，把西岸仓库设为车辆抢修点。玩家夺取西岸后，可让受损战车就近恢复，再回到中央货场参战。以下参数供首轮试玩，尚未实装。

| 情境 | 建议规则 |
|---|---|
| 使用 | 己方步兵占领后，把受损坦克、步兵战车或自行火炮开进装卸场。车辆静止且连续 5 秒未开火、未受击，自动开始抢修。 |
| 吞吐 | 每次修一辆，先到先修；每秒恢复最大生命值的 2%，到 75% 停止。重伤车辆可恢复行动，工程组仍可在其他地点继续维修。 |
| 争夺 | 敌方步兵进入占领区即暂停抢修；易手后服务随归属转移。车辆离场、开火或受击时中断，可立即执行移动命令。 |
| 提示 | 装卸场只标出一个抢修位。选中车辆时显示「抢修中」和预计完成时间；发生争夺时显示「据点争夺中」。 |

首轮验收：把一辆 35% 生命的坦克开入己方仓库，无干扰时 20 秒完成维修（另计 5 秒脱战）；敌人进圈后维修立即暂停。双方适用同一规则，任何状态都不产生军费。中央货场先保持现状，避免短距离内连续覆盖两座抢修点。
