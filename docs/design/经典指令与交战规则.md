# 经典指令与交战规则 · v0.17.0

日期：2026-11-06。对应用户提出的混编散开、点选失败、确认闪光过慢和红警指令要求。

## 调研依据

1. [Westwood《红色警戒 2》原版手册公开转录](https://manualzz.com/doc/24314810/westwood-studios-red-alert-2-user-manual)：Mouse Control、Guard Mode、Attack Move、Way Points 与键位表。采用左键选中/下令、右键取消，G 警戒后回位，Ctrl+Shift 攻击移动，Ctrl+Alt 驻守/护卫，F 跟随镜头等定义。按住 Z 规划多个位置、松开后执行；闭合路径用于巡逻。
2. [原版 Rules.ini 的社区存档](https://github.com/FreemanZY/Command_And_Conquer_INI/blob/master/Command%20%26%20Conquer%20Red%20Alert%28tm%29%20II/Rules.ini)：读取 MTNK 的 `OpportunityFire=yes`、`Crusher=yes`，E1 的 `Crushable=yes`。本项目的主战坦克据此允许不取消移动路线的机会射击与强制移动碾压敌方步兵。不把灰熊的配置推广到所有兵种。
3. [Phobos 开发者文档：Target scan/guard range customizations](https://phobos.readthedocs.io/en/latest/Fixed-or-Improved-Logics.html#target-scan-guard-range-customizations)：未显式配置的 GuardRange 取武器最大射程；记录原引擎扫描扩展及 16 格上限。Phobos 本身是扩展工程，其新增 AreaGuardRange/MaxGuardRange 配置不冒充原版提供的玩家选项。

手册明确了操作语义，没有公布足以逐帧复刻的全部 RA2 引擎实现。以下是本项目中的落地规则；没有移植原版代码或图集，也没有声称单位数值与原版完全相同。沿用现有地图、兵种和生产经济，不为复制快捷键虚构尚不存在的外交、老兵等级、超级武器或建筑出售系统。

## 当前输入

主菜单「规则介绍 → 经典指令」可在游戏中查看。截图：[经典指令](../经典指令.png)。

- 左键点选、拖框，Shift 增减选择，右键取消选择。重复点同一单位保持选择；这取代本游戏旧版的再次点击取消。
- T 选择屏幕内同类，快速连按选择全图同类；Ctrl+1～9 编组，1～9 召回；P 全选部队，M/N 前后切换。
- 左键地面移动，左键敌人点名攻击，Ctrl+Shift+左键攻击移动。Ctrl+左键强制开火，可伤友军；Alt+左键强制移动，主战坦克可碾压敌方步兵。
- G 当前驻点警戒；Ctrl+Alt+地面到达后警戒；Ctrl+Alt+友军护卫单位/建筑。S 取消当前任务，仍保留空闲自卫；X 散开；D 批量展开/装卸。
- 按住 Z 依次点击路径点，松开同时执行；点击已标出的第一个目的地点闭合巡逻。S 或新命令取消后续路径。
- F 跟随镜头，手动平移退出；H 基地，空格最近事件，Ctrl+F1～F4 保存镜头，F1～F4 召回。Q/W/E/R 打开建筑/防御/步兵/车辆生产类别。
- F5 手册、侧栏「辅助范围」、滚轮缩放属于本项目保留的便利功能，不声称是原版对应功能。

## 点选手感

小兵与车辆先进行不透明像素命中，再使用小范围容差；小兵的容差设最低屏幕尺寸，缩小时仍可点中。移动单位优先于建筑的大面积地基命中。鼠标按下时锁定目标，松开时仍对该目标执行，避免单位跑走后误把点击解释成旧队伍的移动指令。框选需超过 7 个实际屏幕像素，悬停角框与最终点选使用同一命中函数。死亡、登车、不可见目标不会使用过期选择。

## 交战任务

| 任务 | 搜索与行动 | 接敌结束 |
|---|---|---|
| 普通移动 | 不主动追敌；坦克可向武器射程内目标机会射击，不清空路线 | 继续到指定位置 |
| 空闲/停止 | 在武器射程内自动选敌，可对来火还击 | 停在当前位置，无驻点回归要求 |
| 攻击移动 | 使用扩展搜索范围；停在射程边缘交战 | 回到原目的地路线 |
| G 警戒 | 记住驻守位置；限制目标在驻守区域内 | 返回驻守位置 |
| 到地点警戒 | 先执行普通移动，到达后启动警戒 | 返回指定驻点 |
| 护卫 | 驻点随目标移动；护卫建筑时选择外围位置 | 重新跟随；对象死亡后原地警戒 |
| 手动点名/强制开火 | 指定目标优先，不被自动选敌抢走 | 目标失效后结束；强制打地需停止或新命令 |

本项目普通索敌范围取当前武器射程；攻击移动和区域警戒取 `min(2 × 武器射程, 16 格)`，替代统一加三格。固定武器仍只在射程内作战。目标是否可见、瞄准和装填也影响实际开火；不能把进入辅助圈理解成必然立即产生一发炮弹。地形、寻路、目标优先级及秒制更新时间是本项目适配，不声称已逐帧验证为原版行为。

默认隐藏选中单位的双圈。侧栏开启辅助后，金圈表示武器射程，绿虚线表示扩展搜索；警戒时绿圈以驻点为中心。辅助圈是解释本游戏规则的可选显示，未把它包装成原版红警的默认 UI。

现有坦克图集的炮塔和车身没有独立分层。机会射击保持车身行进方向，弹道指向实际目标；独立炮塔转动仍需后续素材支持。待验收的动画素材继续只存档，不应用。

## 编队与验证

恢复默认混编同速，并根据同组成员沿行军方向的进度平滑配速，落后者可按自身速度追赶。堵塞超过 2.5 秒的成员暂不参与全队速度限制，防止全队被一个堵点拖停。保留原有独立落点、八方向车辆移动、局部让行和矿车队列。这是本项目的队伍聚拢机制，不声称来自原版寻路源码。

新增测试覆盖实际移动任务的结果：普通移动与攻击移动差异、坦克移动中射击、警戒越界回归、目的地警戒、移动护卫与对象死亡、路径点完成/巡逻/S 取消、强制碾压。窗口测试覆盖三档缩放下的小目标、鼠标按下后单位移位、已有选择时换选、Shift、编组 9、G/F/X/Z/QWER 和 0.2 秒闪光。

12 个混合单位在 20 Hz 与 60 Hz 的前九秒行军中，最大进度差分别为 34.7 和 35.1 世界单位，约 1.5 格，之后全部抵达。另保留 20 车绕建筑、6 矿车共用一厂、完整教程、两类歼灭战及滚屏回归。测试结果不是任何地图布局下都不会拥堵的保证。
