## 共同标尺

单格边长仍为 24 世界单位；默认镜头仍为 1.05，UI 与视口没有改小。所有建筑、单位、碰撞边界与地图都以这一格为参照，屏幕像素只是最终投影结果。

| 对象 | 本项目采用的地格尺度 |
|---|---|
| 指挥部 | 地基 3×3 |
| 电站、雷达、防御阵地 | 地基 2×2 |
| 兵营、精炼厂 | 地基 3×2 |
| 车辆工厂 | 地基 4×3，坡道包含在内 |
| 主战坦克 | 底盘长 1.00 格，不含炮管 |
| 步战车 | 底盘长 0.95 格 |
| 火炮 | 底盘长 1.10 格 |
| 工程车、矿车 | 底盘长 1.05 格 |
| 步兵 | 默认镜头可见高度约为一格投影横宽的一半；不将整张含留白图集当作人体尺寸 |

车辆底盘长由源模型测量，使用相同的正交投影换算，且全部方向、换色、残骸与点选共用。显示大小先按地格确定，再以可见底盘计算单位间交通半径（显示外接半径 / 0.94），不再倒过来由旧道路碰撞半径压缩模型。狭窄道路的导航半径保留；炮管、天线允许二维遮挡。坦克之间硬性车心距离约 30.68（1.28 格），一般同向行驶舒适留距约 38.68（1.61 格）；编队落点间距 42（1.75 格）。

步枪兵和工兵显示尺寸由 48 改为 60、反装甲兵由 50 改为 62，仍通过现有图集透明边缘得到实际轮廓，未粗糙化素材。一像素选中线和黑边血条保留。

## 建筑为何原先越格

旧建筑原画的标注是墙脚接点，未包含全部台阶、坡道。测得工厂地面纹理在局部深度轴上最远到 1.391（该轴一整栋为 1），对应伸出约 1.17 个地格；指挥部到 1.189、兵营到 1.134、雷达到 1.149。

本次重新映射带纹理的建筑立体表面：将完整落地范围纳入原有地基，保留垂直高度和原有材质；六种建筑重新导出己方、敌方与残骸图集。基座四角严格对应逻辑占格，落地构件收在边界内；屋顶与天线在屏幕上的高处遮挡不作为地面越界。精炼厂原三维模型及底板已基本位于 3×2 范围，无需替换风格。中立港务中心保持原地标素材。

工厂卷帘门的四个定位点由同一映射生成，避免房体改了而门仍画在旧位置。选中建筑显示实际地基的一像素角标；放置网格、阻挡与绘制地基共用尺寸，不把扩大碰撞盒作为掩盖素材越界的方法。旧建筑原画、标定与图集保存在 `art/archive/building-ground-before-20261106`。

参考 [OpenRA 的 RA2 建筑定义](https://raw.githubusercontent.com/OpenRA/ra2/master/mods/ra2/rules/allied-structures.yaml)：它将地基尺寸、不可通行位置和出口位置分开定义，例如电站 2×2、兵营 3×2，工厂另有可通过的出口部分。该源是重实现项目，不代表取得原版引擎源码；本项目采用上述自己的尺寸，不宣称数值逐项照搬。录像与用户截图来源仍见 [视频参考记录](战场比例与视频参考.md)。

## 地图容量

实际地图从 105×60 扩建为 140×90 格，世界范围从 2520×1440 扩至 3360×2160，总面积从 6300 格增至 12600 格，增加 100%。增加东部与南部道路、可展开地块和四组矿区（总计 12 组／48 个矿点）。正式敌方基地迁到新区域内有足够余地的铺装区域，配套调整近矿位置。新手训练仍在原区域。

没有通过调小视窗或降低默认镜头倍率制造扩图效果；同一画面中一格仍然一样大。矿车外围作业位置增加到两格范围，卸矿侧位为 ±1.5 格，等候位改按实际车身间距选择，避免更大的车体互相阻塞。

## 验证与交付

- 七种可建造建筑在三档缩放下的底板接点与地格角点重合；统一比例图中格线按各建筑地基对齐，不将不同建筑放大到相同展示宽度。
- 步兵和三类车辆实际驶入新增东南区域，探索与边界检查通过；20 车绕建筑、六车路口、矿车拥堵与双边经济链检查通过。
- 完整教程、装甲／步兵火炮两种战役测试通过，脚本分别在 237／278 秒获胜，不代表玩家通关时间。
- 一像素线、血条、换色、出厂、选中和原生窗口交互回归；扩大地图后地面滚动缓存保持 64 MiB 上限，缓存边缘无接缝。
