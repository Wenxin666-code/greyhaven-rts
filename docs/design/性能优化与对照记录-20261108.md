# 性能优化与对照记录 · 2026-11-08

本轮仅更新本地，不提交、不推送、不发布 GitHub。比较对象是本轮开始前的本地游戏，已经包含尚未发布的防御阵地和基地守备调整，不是干净的 v0.20.0。

## 改动

- 寻路按空间小区索引建筑和临时车辆阻挡。每条短连接只检测附近矩形，仍用原来的完整线段碰撞判定，保留斜角、地形高差和车辆八方向规则。长线段先排除建筑阻挡，再检查沿途地形。
- 永久探索记录跳过位置、阵营、视野都未改变的单位，以及已全部揭开的迷雾区块。移动、占领、单位类型改变和完工仍在原有时刻更新视野。
- 寻找射击位置时一次收集周围的建筑、部队与预定站位，减少逐候选点扫描全军；自动索敌先排除距离以外的目标。
- 战场地形缓存按投影中实际可能出现的树冠、阴影和高地边缘计算绘制范围；选关全图预览保持原有范围。画面外贴图和阴影先做简单边界检查，小地图矿石标记合批绘制，鼠标在侧栏时不拾取地图单位。
- 静态通行数据在进入关卡时准备，避免第一辆车或第一名士兵接单时临时扫描整张地图。建筑、临时车辆与实际路径仍按需更新。

没有降低画质、动画帧数或逻辑更新频率；没有修改移速、碰撞体积、射程、采矿收益、AI 进攻阈值、生产速度或地图布局。

## 正式更新频率下的对测

原版与本轮版在同一进程中逐次交替执行，先后顺序每次轮换，减少电脑负载波动造成的偏差。第三关运行 18,000 次更新，步长 1/30 游戏秒，实际累计 599.942 游戏秒。玩家正常付费发展并驻守，五个 AI 按当前规则交战；不加载美术、不显示窗口。耗时包含玩家模拟发展指令与本次逻辑更新，不包含写文件和状态摘要。

| 指标 | 修改前 | 修改后 |
|---|---:|---:|
| 平均每次更新 | 2.118 ms | 1.187 ms |
| 95% 更新不超过 | 5.726 ms | 3.125 ms |
| 99% 更新不超过 | 15.675 ms | 6.515 ms |
| 超过 50 ms 次数 | 50 | 13 |
| 最慢单次更新 | 260.763 ms | 257.982 ms |

平均运算耗时降低 44.0%，超过 50 ms 次数减少 74.0%。60～540 秒的 9 次摘要完全一致：资金、单位位置与血量、生产进度、路径、载矿与迷雾。额外的 0.1 秒步长、600 秒推演也通过 10 次相同摘要比较；前期沟通中的较大改善幅度来自该快速推演，最终以这里的 30 Hz 对测为准。

## 原生绘制

本机以 1920×1080、默认战术缩放，在离屏位图上运行真实 WinForms/GDI+ 绘制流程。第三关全图已探索，六方共增加 288 个移动单位、84 座建筑与一座我方雷达；可见内容由相机位置决定。每场景 180 帧，不同时运行其他测试；下表采用第 60～179 帧，包括常规动画和界面更新。这里测的是绘制耗时，不是包含运算和显示器同步的实际游戏 FPS。

| 场景／指标 | 修改前 | 修改后 |
|---|---:|---:|
| 原地画面，中位绘制耗时 | 8.51 ms | 8.66 ms |
| 连续滚屏，中位绘制耗时 | 8.95 ms | 9.41 ms |
| 连续滚屏，95% 帧不超过 | 17.59 ms | 18.43 ms |
| 首次绘制完整视图 | 1175.43 ms | 1298.29 ms |

绘制数据在重复运行中有波动，本轮没有证明滚屏绘制本身获得稳定提升；确定有效的改善主要来自逻辑运算。首次进入陌生视区的缓存生成仍是后续瓶颈。三张最终压力场景截图与修改前逐像素一致。

## 正确性与局限

- 30,000 个随机与边界连接，对比完整障碍扫描一致；既有 28,800 个精确连接检查通过。
- 移动、静止、占领、视野变化和完工下，增量迷雾与完整扫描逐格一致。
- 24 个海岸、林地、高地及负坐标视图与旧绘制器逐像素一致；三个战术缩放的拼块接缝检查、64 MiB 地形缓存回收、切换关卡失效检查通过。
- 采矿路线、繁忙与封闭泊位、移速、固定守军、余兵出击、付费炮台、五方 AI、公平资金、受袭回防、第三关唯一出入口和首次采矿收入专项检查通过。
- 不是全量美术／全部关卡通关验证。比较只覆盖这一个确定性对局和上述绘制场景，不能保证所有电脑或极端拥堵下稳定 60 FPS。寻路尖峰仍存在，第一次看到新区域也仍需生成缓存。无美术运算测量保留了首次通行数据生成开销；桌面入口已将它移到进入关卡时。

## 复现与原始记录

单版本运算测量：`pwsh -NoProfile -File scripts/measure-performance.ps1 -Seconds 600`，默认正式 1/30 秒步长。纯性能等价检查：`pwsh -NoProfile -File scripts/build.ps1 -PerformanceVerify`。

对测与绘制原始 CSV、汇总 JSON、输入源码校验值保存在 [performance-20261108](../performance-20261108/)。同进程前后版本对测脚本与本轮开始前的源码快照保留在项目 `.cache` 的本轮性能工作目录，避免把旧版本源码重复加入正式项目。
