# 河湾镇滚动缓存优化

2026-11-07，本地未发布，基于 v0.18.0 之后的队列与投降修改继续开发。

## 问题与改动

原来的河湾镇地形只缓存一张带余量的可视区域。镜头移过余量边界时，需要在同一帧重新绘制整片草地、水面、道路、悬崖与树木，造成规律性停顿。

新增投影世界坐标图块：256×256 物理像素，每边保留 3 像素采样余量；相邻图块复用原有地形绘制与纹理。镜头小幅移动只平移现有图像，重建可视缓存时拼接已准备的图块。普通帧最多提前准备一个附近图块，分散集中绘制成本。缓存上限 64 MiB，按最近使用情况淘汰；缩放、窗口比例和地图对象改变时失效，释放窗口时一并释放。

树木裁剪范围覆盖树冠和落地阴影，避免图块边缘漏绘。训练图与河湾镇的完全不透明地形缓存直接复制，避免无用透明混合；战争迷雾只提交与可见区域相交的遮蔽块。游戏建筑、人物、坦克、占格、碰撞、移动和视角范围保持原设定。此次不加载待验收的建筑蓝本。

## 同场景测量

Windows 原生离屏 1920×1080，默认倍率 1.55，河湾镇高地附近，24 名额外单位，全图揭示，连续来回平移 96 帧。以下属于同机指定场景数据，非所有硬件的帧率保证。

| 帧类型 | 优化前中位 | 优化后中位 | 优化前 P95 | 优化后 P95 |
|---|---:|---:|---:|---:|
| 普通滚动帧 | 5.09 ms | 7.11 ms | 8.58 ms | 8.49 ms |
| 跨可视缓存边界 | 165.16 ms | 10.55 ms | 166.32 ms | 10.86 ms |

提前准备图块会给部分普通帧增加少量工作，明显停顿来自集中重绘的尖峰。本轮测量中重绘帧约减少 94% 用时。初次进入、跳转远处或改变缩放仍需准备新区域；不承诺完全没有首次加载成本。

带部分战争迷雾的独立复测：普通帧中位 8.70 ms、P95 9.73 ms；跨缓存帧中位 7.11 ms，但一次新区域准备仍达到 37.74 ms。迷雾单项中位由 6.77 ms 降至 3.15 ms。测试期间也出现过整体绘制耗时升高的轮次，原始日志保留；最终表格采用没有其他回归并行的独立测量，不能将数字等同于所有场景实际帧率。

## 验证

`./scripts/build.ps1 -ScrollPreview` 可重做测量及正确性检查，`-ScrollVerify` 只执行正确性检查（也已纳入 `-Test`）：三档战术倍率（1.05／1.55／2.4）、树林／河岸／高地，原绘制结果与图块结果逐点采样比对，未出现超过 3 色阶的差异；覆盖拼接、缓存淘汰、64 MiB 上限及重新进入关卡失效。训练地图另行测量，没有套用河湾镇绘制缓存。

原始日志位于本机 `.cache/scroll-before-v019.log` 和 `.cache/scroll-verified-v019.log`；最后独立测量位于 `.cache/scroll-isolated-v019.log`，窗口与河湾镇交互验证位于 `.cache/scroll-interface-v019.log` 和 `.cache/scroll-release-check-v019.log`。

最终验证：当前程序的缩放、点选、雷达、驻防和三方经济检查通过。复杂三方场景的另一组离屏滚动复核仍测得中位 59.4 ms、P95 69.1 ms，说明现有绘制在部分场景仍有慢帧；本次改善缓存边界的周期性尖峰，没有达到全场景稳定 60 帧。两个场景的差异保留在日志中，不将单一测量结果推广为整体帧率。
