# 断线前沿（暂名）
单人现代战争即时战略 · 第一关《灰港登陆》 · 初步构想 v0.1 · 2026-11-04

## 游戏定位
玩家统率一支先遣部队，在架空的沿海地区登陆。一次突袭切断了港区与内陆的联系。玩家从工程车和一个步兵班起家，建立基地、生产装甲力量，在敌军增援抵达前打通港口。主角贯穿简报和无线电剧情。建设、部队指挥与地图控制决定胜负。

## 一局怎么玩
目标时长 20～25 分钟。胜利条件是占领港务中心，并守到己方运输船靠岸。

| 阶段 | 战场变化 | 关键选择 |
| --- | --- | --- |
| 登陆立足 | 展开工程车，建电站和兵营，侦察周围街区 | 先取安全低收入仓库，或冒险抢下中央大货场 |
| 争夺外围 | 建车辆工厂，用侦察车探路，步兵驻守建筑 | 用第一笔收入造步战车抢地，或攒军费升级坦克 |
| 找到突破口 | 坦克与反装甲小组封锁公路，港区开始集结增援 | 从公路强攻，穿城夺观察站引导炮击，或袭击侧翼资源点调动守军 |
| 攻下港口 | 占领港务中心后敌军反攻 | 分配留守基地、拦截增援与港区防御的力量 |

## 基地、经济与生产
军费来自指挥部的少量保底收入和已占领的仓库、货场。占点后自动结算。丢失外围资源点仍有反击机会。电力限制基地运行。油弹及运输交由部队自行保障。基地周围可直接建设，工程车可到外围展开分基地；前置工厂缩短增援路线，也更容易遇袭。

| 建筑 | 作用 |
| --- | --- |
| 指挥部 | 提供基础军费，生产工程车 |
| 电站 | 为基地供电。电力不足时工厂生产放慢，雷达下线 |
| 兵营 | 训练步兵班、反装甲小组和工程兵 |
| 车辆工厂 | 生产侦察车和步战车，升级后开放坦克与自行火炮 |
| 雷达站 | 探测附近移动的敌方车辆，解锁短时侦察无人机 |
| 防御工事 | 建造时选机枪阵地压制步兵，或反装甲阵地封锁公路 |

## 作战单位
| 单位 | 适合的任务 | 需要防范 |
| --- | --- | --- |
| 步兵班 | 低成本占点、驻楼、控制街区 | 在空地遭遇步战车 |
| 反装甲小组 | 在街角和林缘伏击装甲车辆 | 暴露后被步兵或火炮清剿 |
| 工程兵 | 修理车辆、夺取并修复设施 | 脱离掩护 |
| 侦察车 | 快速探路、监视侧翼 | 与敌方主力正面交战 |
| 步兵战车 | 运送步兵、提供伴随火力 | 坦克和反装甲伏击 |
| 主战坦克 | 在开阔地击败装甲，突破正面防线 | 在窄街失去步兵掩护 |
| 自行火炮 | 利用前线视野从远处压制阵地 | 观察中断或快速部队绕后 |

另有负责建设的工程车。典型战术场景是让步战车运送步兵到街口，步兵下车侦察并清理伏击点，再让坦克入城。

## 发现与确认
雷达只能提示移动信号及其大致方向。前线步兵、侦察车或短时无人机获得视野后，才能确认具体兵种，火炮才能持续跟踪射击。失去视野后，地图保留带时间的最后已知位置，玩家仍可手动指定区域压制。守方可驱离观察员，或用轻车从侧翼佯动。

## 主角与任务
先遣营指挥官搭乘指挥车随队登陆。指挥车展开后成为临时观察所，扩大局部视野，收起后才能移动。常规关卡中车辆被毁，指挥官撤离，玩家仍可继续。专门的护送任务可另设生存条件。首版暂缓个人等级、装备和技能栏。

## 第一版边界与实现顺序
一张可重玩的单人地图，敌我共用基础兵种。敌人也要占资源、从工厂生产。摧毁敌方车辆工厂，应能观察到后续装甲增援中断。

1. **先打磨五分钟的街口遭遇战。** 用步兵、步战车和坦克验证框选、编队、攻击移动、车辆寻路和战斗反馈。
2. **再做基地经营。** 接入建造、供电、生产队列、自动收入与会扩张的敌人，分别测试快攻和先扩张。
3. **最后完成灰港战役。** 接入三条路线、侦察与火炮、指挥车、任务简报和港口反攻。

首版验收用两种打法通关同一张地图。一局靠步战车抢下货场，以经济优势正面推进；另一局让步兵穿城夺观察站，以少量装甲配合炮火攻港。玩家应能指出哪一处地形、情报或生产选择改变了结果。造价、生产时间、占点速度、常规失败条件和敌军反攻时机留待灰盒试玩确定。
