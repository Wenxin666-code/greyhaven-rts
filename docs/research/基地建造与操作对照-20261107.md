数值参考继续使用上一份报告固定的 CnCNet YR 基础规则版本：`BuildSpeed=.7`、`MultipleFactory=.8`、`RefundPercent=50%`、`RepairPercent=15%`、`RepairStep=8`、`RepairRate=.016`、`MCVRedeploys=yes`。这些参数不能直接声称是所有零售版本、游戏速度下的墙钟秒数。[固定规则文件](https://github.com/CnCNet/cncnet-yr-client-package/blob/e4b5712df96ec3acb05ddbda9fe2ba63e30576ab/game-assets/cncnet.pack/rulesmd.ini)

## 现在怎样操作

| 操作 | 当前本地版行为 |
| --- | --- |
| 展开基地车 | 左键选车，再点车身；也可按 D。空间足够显示金色四向展开指针，不足显示红色禁止指针 |
| 搬迁基地 | 选中基地，左键点可达地面，先收起再驶往目标；D 或面板按钮可原地收起。保留血量百分比，不能反复展开免费修满 |
| 买建筑 | 左键侧栏图标开始生产，图标扫掠显示进度；尚未就绪不会进入摆放模式 |
| 放置建筑 | 点击“就绪”图标，或按 Q／W 取出对应栏的就绪建筑，再左键放置。无效落点保留建筑；地图右键只退出预览 |
| 暂停、继续、取消 | 对生产图标右键暂停，左键继续；再次右键取消并退回实际已付金额。未开始的单位队列不凭空退款 |
| 资金不足 | 保留进度等待收入；到账后继续，不扣成负数，也不因钱不够清空命令 |
| 生产类别 | Q 建筑、W 防御、E 步兵、R 车辆。建筑与防御各有一个独立生产项目，完成未放置时占用本栏 |
| 单位生产 | 同类设施共享队列，双击或 D 指定主要出口；仍保留四项队列上限。工程车改在车辆工厂生产 |
| 维修 | K 或侧栏“维修”进入模式，点受损己方建筑开启／关闭维修；右键退出模式。每 0.96 游戏秒恢复最多 8 点生命，按累计修复量计费 |
| 出售 | L 或侧栏“出售”进入模式，点己方非民居建筑出售；右键退出模式。返还本作基础价格的 50%，收起动画后移除；没有爆炸残骸 |

按键对生产图标的右键与对地图的右键分别处理，避免把暂停生产误当成取消部队选择。工程车与驻军撤出的部署动作使用金色指针；移动为绿色、攻击为红色，禁止位置有红色斜杠，轮廓改为清晰的像素边缘。

## 建造时间

本作保留原有的较低价格体系，并采用“价格 × 0.042”作为基础生产游戏秒数，再叠加电力、同类设施倍率和全局速度。下面是一座同类工厂、正常供电、速度 ×1 的值。它们是本作价格代入规则系数后的结果，**不是照抄原作高价建筑的绝对用时**。

| 建筑 | 本作价格 | 侧栏基础生产时间 |
| --- | ---: | ---: |
| 电站 | 170 | 7.14 秒 |
| 兵营 | 210 | 8.82 秒 |
| 车辆工厂 | 380 | 15.96 秒 |
| 雷达站 | 240 | 10.08 秒 |
| 间谍卫星 | 750 | 31.50 秒 |
| 防御阵地 | 235 | 9.87 秒 |
| 矿石精炼厂 | 390 | 16.38 秒 |

放置后的装配动画统一约 1.2 游戏秒，基地收起／展开也用这一时长；这是本作动画节奏，不冒称原版帧数。缺电仍按本作的 45% 生产速度处理。多一座同类设施，所需工时乘 0.8；两座约是单座 1.25 倍生产速度。

## 占格与出口

取消此前兵营、车辆工厂、基地和民房前方额外一格的硬性禁建区。建筑按现有模型的实际地基逐格检查，单位、其他建筑、矿石、水面、树木和高差会阻挡；平坦道路可以摆放，桥面和坡道不行。可从已建成的己方常规建筑附近扩展，以建筑边缘约两格为范围；中立民房和防御阵地不作为扩展支点。

绿色表示该地基格可用，红色标出实际阻挡；超出建造范围或地基不平时整个预览不可用。没有再用整座建筑的实体预览遮住地面，也不把厂门画成虚构的额外占地。

可以贴建不等于出口不需要通路。真正堵住兵营、工厂或精炼厂门口时，单位会等待、闲置友军让路，矿车执行既有排队／转厂逻辑，不穿过邻楼。占地合法性和出入口是否畅通是两个不同判断。

## 连带修正和边界

河湾镇的工兵曾在地形格角落停住：长线按固定距离取样漏掉了极薄的碰撞区，实际短步却检测到。现在按单位中心及占地四角跨过的地格边界分段检查，规划、预选和步行碰撞使用相同宽度；没有修改单位模型或碰撞尺寸。两方电脑仍可先后占领、争夺同一房屋。

电脑与玩家走同一套建筑生产、付费、就绪和落地流程；不会因为已付费后余额低于原先的规划预算，就忘记放置已完成的卫星。

当前任务默认允许基地重新部署，没有新增开局设置页。收起时已付的建筑项目保留，等待可用指挥部后继续；已完成项目也保留。出售、被夺或失去生产设施后的队列接管／退款仍按本作明确的规则执行，不宣称完整复刻原作全部边界情况。保留原有科技树、价格、单人三方敌对设定；没有新增海空军、联机外交／聊天和老兵等级体系。

本轮验证覆盖：逐步扣费与零资金等待、暂停／取消／退款、两个建筑生产栏、无效放置保留就绪项目、出口不再硬性保留、搬迁不回血及订单暂停／恢复、维修与出售、鼠标和快捷键、三方生产和地形角落通行。装甲自动战役约 337 秒胜利；步兵／火炮方案改为先集结首批火炮再进攻，约 327 秒胜利，仍用同一 560 秒上限。没有以修改部队战斗数值来让测试通过。
